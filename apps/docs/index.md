## Technical-preview guide

This independently deployable guide covers the current Chat, Work, Code,
Project, provider, extension, appearance, security, recovery, and remote-access
boundaries of the Octant technical preview. Planned behavior is identified as
planned rather than described as available.

The static build has no dependency on the Octant desktop or server runtime.
