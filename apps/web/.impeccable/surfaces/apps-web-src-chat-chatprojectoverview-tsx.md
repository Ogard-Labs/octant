# Chat Project home brief

- Scope and mode: Chat Project landing surface, Operate mode.
- Audience and job: Start or resume Chat work inside a virtual Project without treating the page as an admin dashboard.
- Primary task: Name the Project, start the next thread, and only then scan live Project facts.
- Content and states: Empty home, populated sections, loading, stale, unauthorized, and unavailable. Empty cards stay hidden.
- Constraints: Preserve Chat-only authority, provider-neutral thread creation, keyboard access, and existing memory/archive actions.
- Direction: Composer-first home inside the existing warm-neutral Octant world. No new identity.
- Memorable moment: A new Project looks like a quiet start screen, not a stack of empty cards.
- Open decisions: Whether a later populated Project should still keep the composer above the facts.
