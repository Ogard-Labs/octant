# Canvas HTML frames threat model

- Date: 2026-10-10
- Threat model id: `canvas-html-frames-v1`
- Status: Accepted with
  [0165](../decisions/0165-canvas-artifacts-are-documents-designs-and-prototypes.md).
  Static frames that run nothing ship today under
  [0164](../decisions/0164-canvas-designs-are-html-in-a-frame-that-runs-nothing.md);
  measured, themed, asset-bearing, and running frames do not ship until the
  mitigations below that apply to them are implemented and tested.
- Scope: agent-authored HTML, CSS, and script drawn in a Canvas `design`
  frame, in the sidebar, the thread, preview, authenticated snapshots, and
  HTML export

## What the frame can hold

A frame holds what its author wrote, plus assets the server resolved for it
under the thread's authority. The author is the agent working for this
person, which already has that content and its own tools. The boundary
therefore protects Octant and the person from the frame, not the frame's own
content from its author: a frame must gain nothing the agent did not already
have, must not reach anything beyond its own bytes, and must not cost the
person their app.

## Assets

- Octant renderer origin: cookies, storage, DOM, RPC, preload, host tokens
- Project files and artifacts beyond the assets a frame names
- Loopback services and the network from the person's machine
- Renderer responsiveness (hang, memory, GPU)
- The person's trust in what is Octant chrome and what is a frame
- Snapshot viewers and export recipients

## Explicit non-goals

- Typed catalog blocks, including `tabs`, `columns`, diagram styles, Gantt,
  and Mermaid import; they render first-party components and no markup
- Public or anonymous share links
- A frame that runs script with `allow-same-origin`; no tier admits it
- Protecting frame content from the agent that wrote it

## Frame tiers

| Tier                        | Document                                          | Sandbox                                                                       | Policy                                                                                                                                                                                                             |
| --------------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Static (0164)               | `srcdoc`                                          | empty                                                                         | Frame policy below, narrowing the inherited app policy                                                                                                                                                             |
| Static, measured and themed | `srcdoc`                                          | `allow-same-origin` only                                                      | Same; no script can run, so same origin grants the page nothing it can use                                                                                                                                         |
| Running                     | Served by the host route with a single-use ticket | `allow-scripts` only, in the parent and in the response's `sandbox` directive | `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; media-src data: blob:; connect-src 'none'; frame-src 'none'; form-action 'none'; base-uri 'none'` |

The static frame policy is today's: `default-src 'none'; style-src
'unsafe-inline'; img-src data:; font-src data:; base-uri 'none';
form-action 'none'`. The app policy needs a `frame-src` that admits the host
route and nothing else.

## Threats and mitigations

| ID  | Threat                                                          | Mitigation required before the tier ships                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | Running frame reads Octant state                                | Opaque origin: no `allow-same-origin` in the attribute or the response `sandbox` directive. No preload, host object, or credential reaches the page. A test asserts no frame is ever given both `allow-scripts` and `allow-same-origin`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| F2  | Static frame with `allow-same-origin` acts as Octant            | No `allow-scripts`, so no script, event handler, or `javascript:` URL runs. The inherited app policy and the frame policy still apply. Markup refusals keep rejecting `meta`, `base`, embedded documents, forms, and non-fragment links.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| F3  | Frame sends data out                                            | `connect-src 'none'` and no remote media, fonts, frames, or form targets. Static frames load nothing at all. WebRTC is not governed by content policy: desktop sets a WebRTC policy that refuses non-proxied UDP, and a remote browser keeps it as a residual, bounded by what the frame holds: its author's content and named assets.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| F4  | Ticket or session credential leaks to the frame                 | The frame URL carries a single-use ticket that expires in seconds and authorizes one Canvas version's page, never a session token. Responses send `Referrer-Policy: no-referrer` and `Cache-Control: no-store`. A replayed or expired ticket is refused.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| F5  | Asset reference reaches beyond authority                        | The server resolves only asset ids the definition declares, under the thread's mode and Project authority, before the page is drawn. A Chat Project reaches only its artifact library. A frame cannot request an asset at run time. Unknown or refused ids draw a placeholder and a preview warning.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| F6  | Running frame hangs or exhausts the renderer                    | Desktop runs sandboxed frames out of process; the feature is verified on the shipped Electron and enabled explicitly if it is not on by default. The bridge sends a heartbeat; a frame that misses it is removed and shown as stopped, with Run again. The thread starts a running frame only on Run. A remote browser keeps a tab hang as a residual a reload clears.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| F7  | Frame navigates the app, opens windows, or navigates itself out | No `allow-top-navigation`, `allow-popups`, `allow-forms`, or `allow-modals`. Static frames keep fragment-only links, and with no script they cannot navigate otherwise. A running frame can still set its own `location`. The page it loads runs its own script under its own policy, not the frame policy, and stays sandboxed only as far as the attribute reaches: opaque origin, no top navigation, no popups. Desktop cancels every navigation of a running frame except to its own ticketed page (Electron `will-frame-navigate`), so on desktop the frame stays network-contained. A remote browser cannot cancel it: there the navigated page can make any request a web page in that browser can, before and after it loads. The parent removes a frame on its second load, which limits how long such a page stays on screen, not what it sends. 0165 accepts this remote exposure, bounded by what the frame holds; the Run control in a remote browser says the prototype is not network-contained there. |
| F8  | Frame impersonates Octant chrome                                | Frames sit inside a Canvas body with host chrome outside them; a running frame carries a visible running label and its Stop control in host chrome. A frame never draws over the composer, approvals, or dialogs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| F9  | Bridge messages are forged or abused                            | The parent accepts messages only whose `source` is that frame's window, with a known type and bounded fields. Height is clamped; errors are truncated and shown as text. The bridge grants no tool call, journal write, file read, or navigation. Agent script can lie to the bridge; the worst outcome is a wrong size or a missed error.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| F10 | Keyboard focus is trapped                                       | Frame script can swallow Tab or keep refocusing itself, so ordinary focus order is not an escape. Desktop reserves a host shortcut, read through Electron `before-input-event` before any frame sees the key, that stops the frame's hold on focus and moves focus to the frame's host chrome. A running frame never takes focus until the person presses Run or clicks into it. A remote browser relies on the browser's own focus escape (F6 or the address bar) and the Stop control in host chrome; the user guide names both.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| F11 | Shared or exported frame runs unsafely elsewhere                | A snapshot carries frames only when its viewer draws them under this same policy and the sharer has acknowledged that markup is shared as written. HTML export writes each frame as a sandboxed `srcdoc` page carrying the frame policy in the page. Markdown export writes the title.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| F12 | Older runtime draws a new tier unsafely                         | Each tier is a Canvas schema bump; an older runtime refuses the document as a future version.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| F13 | Remote client exceeds authority                                 | Frames, tickets, and assets use the same Canvas and Project authority as any block. A remote client gains no tool through a frame.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## Residual risk

- A running frame in a remote browser is not network-contained: WebRTC (F3)
  and a self-navigation to a page that runs its own script and makes its own
  requests (F7). What it can send is bounded by what the frame holds, which
  its author already had; the Run control says so.
- A tab hang in a remote browser that does not isolate sandboxed frames
  (F6).
- Chromium once stopped painting sandboxed frames that were `inert` or had
  `pointer-events: none` (0164). Every tier keeps frames hit-testable and
  covers a still frame instead.
- The secret filter cannot read markup. Shared frames rely on the sharer's
  acknowledgement, not on scanning.
- Content inside a frame is the author's. A frame can look persuasive; F8
  keeps it from looking like Octant.
